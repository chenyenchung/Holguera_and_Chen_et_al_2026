# Deep/Superficial Figure Workflow

Generates the deep/superficial bias figure PDFs formerly assembled by
`src/manual_ds_stats.r`.

## Overview

The workflow has four stages:

1. Per-neuropil preparation of type-depth inputs and cell-type shards.
2. Type-depth bootstrap testing for `ME_R`, `LO_R`, and `LOP_R`, separately for
   presynaptic and postsynaptic depths, split into cell-type chunks.
3. Combination of per-shard type-depth CSVs into per-condition CSVs and
   `combined_type_depth.csv`.
4. Rendering of deep/superficial figure PDFs from the broad-depth statistics
   workbook and the combined type-depth table.

The type-depth step restores the historical depth input required by the plots;
the current `src/de_analysis` workflow no longer produces this table.

## Usage

```bash
nextflow run src/ds_plot/main.nf
```

For a faster smoke test:

```bash
nextflow run src/ds_plot/main.nf --n_bootstrap 10
```

## Parameters

| Parameter | Default | Description |
|-----------|---------|-------------|
| `annf` | `data/visual_neurons_anno.csv` | Visual neuron annotations |
| `utilsf` | `src/utils.r` | Shared plotting utilities |
| `metaf` | `data/viz_meta.csv` | Neuropil depth-axis metadata |
| `ref_groupsf` | `data/reference_groups.csv` | Superficial/deep reference definitions |
| `broad_depth_cppf` | `src/stats/bin/broad_depth.cpp` | Bootstrap implementation used by type-depth tests |
| `broad_depth_xlsx` | `int/stats/deep_superficial/combined_broad_depth_results.xlsx` | Broad-depth workbook generated by `src/stats` |
| `mat_prefix` | `int/idv_mat` | Directory containing rotated synapse matrices |
| `neuropils` | `ME_R,LO_R,LOP_R` | Neuropils used for type-depth tests |
| `syn_types` | `pre,post` | Synapse directions used for type-depth tests |
| `sparse_limit` | `100` | Minimum synapses for a type-depth test |
| `min_neurons` | `3` | Minimum neurons for a type-depth test |
| `coefficient` | `0.5` | Depth-test threshold coefficient |
| `n_bootstrap` | `1000` | Bootstrap iterations |
| `conf_int` | `95` | Bootstrap confidence interval |
| `type_chunk_size` | `5` | Cell types per type-depth shard |
| `bootstrap_seed` | `1` | Base seed for deterministic per-cell-type bootstrap seeds |

## Outputs

Published under `int/`:

- `Supp_fig_Y1.pdf`
- `Supp_fig_Y1-alt.pdf`
- `Supp_fig_Y2.pdf`
- `Supp_fig_Y3.pdf`
- `Supp_fig_Y4.pdf`
- `Supp_fig_Y6.pdf`
- `Supp_fig_Y6_split.pdf` (spatial origin split by Notch status and neuron class)

Published under `int/ds_plot/type_depth/`:

- Per-neuropil/per-synapse-type `*_type_depth.csv` files.
- `combined_type_depth.csv`.
- `type_depth_summary.txt`.
